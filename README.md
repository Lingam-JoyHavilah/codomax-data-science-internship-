# Data Science Internship Project

## About the Project

This repository contains the tasks and projects completed during my Data Science Internship at Codomax.

The internship provided hands-on experience with Python, NumPy, Pandas, Matplotlib, data cleaning, data analysis, data visualization, and GitHub.

- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook
- GitHub
